# FastAPI Cold-Start Optimized Application

This project implements a multi-stage Docker build for FastAPI with gunicorn, optimized for sub-second container startup times.

## Features
- Multi-stage Dockerfile for production
- Gunicorn with Uvicorn workers
- Sub-second cold-start optimization
- Health check endpoints
- Non-root user security
- Optimized Python packages
